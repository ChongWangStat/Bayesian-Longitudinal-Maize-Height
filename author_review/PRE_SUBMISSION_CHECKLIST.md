# Pre-submission checklist: The Plant Phenome Journal

## Manuscript compliance

- [x] Article type selected: Methods and Techniques.
- [x] Title is sentence case, contains the crop name, contains no abbreviation, and is 12 words.
- [x] Maize is identified as *Zea mays* L. at first mention in the abstract and main text.
- [x] Abstract is one paragraph, 200 words, and 1,425 characters including spaces.
- [x] Plain Language Summary is below 1,000 characters.
- [x] Four Core Ideas are included; each is below 115 characters.
- [x] Keywords and an alphabetical abbreviation list are included.
- [x] Manuscript and supplement are double-spaced with continuous line numbering.
- [x] Main text follows Introduction, Materials and Methods, Results, Discussion, and Conclusions.
- [x] Conclusions are below 200 words.
- [x] Figures and tables appear near first citation and are cited in order.
- [x] References use author–year citations and are alphabetized.
- [x] CRediT-form author contributions, funding, conflict of interest, data availability, AI-use declaration, acknowledgments, and supplemental-material statement are included.

## Scientific and editorial checks

- [x] The novelty is stated as prior-guided image analysis within a Bayesian longitudinal method.
- [x] “Filtering” is defined in the state-space sense and distinguished from image denoising and retrospective smoothing.
- [x] Every reported update is prefix-causal and uses no later image.
- [x] The 2021 validation is described as independent because plants are subject-disjoint and manual outcomes never enter fitting or tuning.
- [x] Manual-height validation, detector agreement, pole stability, calibration, candidate simulation, and temporal transfer support separate claims.
- [x] Camera-row bootstrap inference preserves within-row dependence.
- [x] Comparative claims acknowledge uncertainty versus the single-frame and Gaussian-filter comparators.
- [x] The real-image candidate audit is described as a negative control.
- [x] Cost and processing-time claims are limited because those quantities were not recorded consistently.
- [x] Data and training-provenance limitations are stated in the main manuscript and repository.
