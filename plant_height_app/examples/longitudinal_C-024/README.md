# Clean longitudinal example

This example uses four released images from stationary camera row C-024 on 2 July,
11 July, 18 July, and 30 July 2021. The four tracked plants have usable current-image
measurements at every date, making this the default demonstration for collaborators.

Select **Try the included longitudinal example** and **C-024 · clean four-date
series**. Retain the **Published 2021 fixed-camera setup** calibration and click
**Run plant-height analysis**. The results contain 16 plant-by-image rows, a
height-versus-day plot with uncertainty, annotated images, and downloadable tables.

The dates are the true acquisition dates. Daily, three-day, seven-day, and 30-day
replays in the validation suite test the elapsed-time logic without presenting those
reassigned dates as new observations.
